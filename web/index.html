About this model

NanoChat-X is a decoder-only transformer built from scratch in PyTorch — token and positional embeddings, multi-head causal self-attention, pre-LayerNorm residual blocks and a weight-tied language-model head. It is a learning project, so outputs reflect a small model trained on a local corpus, not a production assistant.
